# 方案—收益—成本—优先级—修改位置 对照表

> 目标：在不破坏当前 `EDCR-V1-Predicted-0.75` 主线结果的前提下，优先恢复 `STOI/ESTOI`，同时尽量保住 `SI-SDR / LSD / HF-LSD` 的收益。

## 说明

- **收益**：对当前核心问题（尤其是 `STOI/ESTOI` 下降、过修复、频谱收益保持）的潜在帮助
- **成本**：实现复杂度 + 训练代价 + 调参难度的综合判断
- **优先级**：基于当前论文阶段的推荐顺序
- **修改位置**：
  - `只改测试`：仅修改推理/评测，不重训
  - `改训练`：需要改训练代码并重新训练
  - `训练+测试`：训练和推理两端都要配合

## 当前阶段最推荐的组合

### 第一梯队（最值得优先尝试）
1. **缩小 `residual_scale` 搜索范围**（只改测试）
2. **残差能量上限**（训练+测试，或先做推理版）
3. **时间差分损失**（改训练）

### 第二梯队（如果第一梯队效果不足）
4. **基础输出保持约束（identity / reliable mask）**（改训练）
5. **clean 样本零残差损失**（改训练）

### 第三梯队（当前不建议优先）
- `SI-SDR` 波形损失
- medium 过采样
- 分带损失
- 条件分支重构（频带门控 / FiLM / 条件排序损失 / 混合训练）
- 位深估计器重构
