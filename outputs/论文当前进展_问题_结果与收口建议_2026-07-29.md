## 3. 当前已经稳定得到的核心结果

### 3.1 固定 scale 路线的主要结论
通过对 `0.55 ~ 0.75` 的细扫，观察到：

- scale 越大，`LSD / HF-LSD` 越低；
- scale 越小，`STOI / ESTOI` 越容易恢复；
- `SI-SDR` 在 `0.65` 左右达到更好的平衡点。

因此，固定 `0.65` 比 `0.75` 更适合作为当前固定 scale 路线下的最终主模型。

### 3.2 当前固定 `0.65` 结果的意义
如果以 `GTCRN` 为内部参考系统，则 `EDCR-Predicted-0.65` 可被理解为：

- 在极小可懂度代价下，提升了时域一致性；
- 同时显著降低了 `LSD` 和 `HF-LSD`；
- 比 `0.75` 更有利于论文中的平衡叙事。

### 3.3 条件机制相关结论
当前 `zero / shuffled / predicted / oracle` 的实验结果表明：

- 四种条件源差异极小；
- 条件排序未形成显著稳定趋势；
- 最终系统的主要收益并不依赖条件信息是否精确，而更多来自残差补偿结构本身。

因此，论文中不宜再把“条件机制显著有效”作为主亮点，而更适合写成：

> 当前系统对条件源变化不敏感，条件信息带来的额外增益极为有限，而主要收益来自轻量残差补偿结构本身。

### 3.4 外部对比的初步结论
在同一批 `smallset` 样本上：

- FullSubNet+ 在 `STOI / ESTOI / SI-SDR / PESQ` 等整体质量指标上表现最优；
- EDCR 在 `HF-LSD` 上更具优势；
- 说明 EDCR 更适合作为轻量级高频谱细节补偿模型，而 FullSubNet+ 更像整体增强能力更强的大模型。

## 4. 当前遇到的关键问题

### 4.1 条件机制贡献有限
虽然退化估计器本身成立，但在最终系统中：
- 条件输入并未明显转化为差异化修复能力；
- `zero / shuffled / predicted / oracle` 差异极小；
- 条件机制无法构成当前论文的核心创新支点。

### 4.2 Windows 下 shard 读取稳定性问题
在正式训练 dynamic scale 路线时，发现：
- `torch.load()` 反序列化 adaptive shard 文件在 Windows 下会发生 `0xC0000005` 原生访问冲突；
- 崩溃位置位于 `AdaptiveResidualShardDataset._load_shard()`；
- 不是模型结构本身的问题，而是缓存 shard 读取方式与系统环境耦合带来的稳定性问题。

目前已经通过：
- 修正版 `AdaptiveResidualShardDataset`；
- `ShardBatchSampler`；
- 线程限制；
缓解这一问题，使 `fixed_pretrain` smoke 能够跑通。

### 4.3 动态 scale 路线尚未完成验证
当前动态 scale 机制在代码层已经接通，但尚未完成以下关键验证：
- `fixed_pretrain` 的正式训练；
- `scale_only` 是否学出 `clean < light < medium < heavy`；
- `joint` 是否在保持频谱收益的同时改善 `STOI / ESTOI / SI-SDR`。

因此，动态 scale 还处于：

> **代码实现基本完成，但实验验证尚未收敛。**

## 5. 当前如果现在就要写论文，应当如何收口

### 5.1 最稳妥的收口路线
如果当前论文需要尽快定稿，建议：

- **不等待动态 scale 最终结果**；
- 直接以 **`EDCR-V1-Predicted-0.65`** 作为固定 scale 路线的最终主模型；
- 把动态 scale 部分作为：
  - 后续工作
  - 或未完成的扩展探索

### 5.2 固定 scale 路线的推荐表述
论文主结论可写成：

> 在固定基础增强器之上，引入轻量残差补偿后，系统在 `SI-SDR`、`LSD` 和 `HF-LSD` 上获得了稳定收益，仅在 `STOI/ESTOI` 上引入极小代价。进一步的推理级残差强度校准表明，`0.65` 是比 `0.75` 更平衡的残差注入系数，可在基本保持可懂度的前提下获得更优的时频综合表现。

### 5.3 条件机制的推荐表述
不建议写成：
- “条件机制显著有效”

更合适的是：

> 条件信息在当前最终系统中的额外贡献较小，系统性能的主要提升来源于残差补偿结构本身。这表明显式退化建模在当前版本下更多提供了可解释性支持，而非强差异化控制能力。

### 5.4 对比实验的推荐表述
对于外部模型对比，不建议把当前 smallset 结果写成最终公平复现实验，而应表述为：

> 基于统一测试样本与统一评测口径的小规模预训练模型对照结果显示，FullSubNet+ 在整体增强质量上更强，而 EDCR 在高频谱保真方面表现更优。该结果说明 EDCR 适合作为轻量级后端细节补偿框架，但完整大规模公平对比仍有待进一步展开。

## 7. 代码和实验当前最重要的结论

当前项目已经从“围绕 `Predicted-0.75` 的固定增强实验闭环”推进到了“尝试引入动态残差控制机制”的阶段。代码层面，动态 scale 方案已经具备训练与验证基础；实验层面，固定 `0.65` 路线已经足够支撑论文定稿，而动态 scale 路线则更适合作为下一阶段方法提升的重点方向。

如果现在暂停开发并在另一台电脑上继续，最重要的任务顺序应为：

1. 完成 `fixed_pretrain` 正式训练；
2. 基于其最优 checkpoint 开始 `scale_only`；
3. 若 `scale_only` 学出合理排序，再进入 `joint`；
4. 若结果不理想，则回到固定 `0.65` 路线收口论文。
