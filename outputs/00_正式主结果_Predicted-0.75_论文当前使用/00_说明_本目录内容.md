# 00_正式主结果_Predicted-0.75_论文当前使用

本目录用于存放当前论文正式使用的主结果，统一围绕 `EDCR-V1-Predicted-0.75` 组织。

## 子目录说明
- `01_系统级主结果`：总体结果、按退化强度分组结果、逐句结果
- `02_Scale对比_0_0.75_0.90`：残差缩放系数对比结果
- `03_条件有效性_完整版`：`zero/shuffled/predicted/oracle` 条件实验
- `04_贡献分解_ZeroCondition对照`：Base/Zero/Predicted/Oracle 的内部参考对照
- `05_统计显著性_改善比例_分布`：Wilcoxon、改善比例、差值分布图
- `06_典型样本频谱图`：light/medium/heavy 的典型样本频谱图
- `07_复杂度与CPU运行成本`：参数量、简化 CPU 时间与 RTF
- `08_汇总文档与回填清单`：汇总文档、回填清单、方法章节草稿等
- `09_论文重构图_对比与消融分离`：按重构后的第四章生成的正式论文图

## 使用建议
写论文时，优先从本目录取图、表和文字结论。
